# Little Study Studio 🌷

An LLM-powered Academic Rescue Planner that helps
students prepare for exams with personalized study plans.

## Features
- Exam countdown
- Preparation risk score
- Personalized study plans
- AI-powered academic assistance

## Technologies Used
- Python
- Streamlit
- Groq API
- python-dotenv

## Installation

Install the dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py

## API Key
Create a `.env` file and add your own Groq API key:

GROQ_API_KEY=your_api_key_here
